# Etiquetas de triage

Equivalencia entre los roles de las habilidades de mattpocock y las etiquetas de este repo (ver `docs/protocolo-agentes.md`).

| Rol en las habilidades | Etiqueta en este repo | Significado |
|---|---|---|
| `needs-triage` | `necesita-criterio` | Falta una decisión de Opus |
| `needs-info` | `bloqueado` | Espera algo externo; el comentario dice qué |
| `ready-for-agent` | `estado:listo` + `ejecutor:codex` | Especificado; Codex lo puede implementar |
| `ready-for-human` | `ejecutor:opus` | Planificación o decisión; no produce código |
| `wontfix` | cerrar como *not planned* con un comentario | No se hace |
